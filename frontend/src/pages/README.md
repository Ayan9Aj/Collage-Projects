# Pages Architecture (Upcoming Stages)

This directory is prepared for subsequent stages of the **GrandStay Multi-Hotel Booking Platform**:

- **Stage 2: Homepage (`HomePage.jsx`)**
  - Hero search banner (Destination, Dates, Guests)
  - Featured luxury hotels carousel/grid
  - Destination categories (Beach, Mountains, Heritage, Urban)
  - Promotional perks and customer trust badges
- **Stage 3: Hotel Catalog & Filtering (`HotelsPage.jsx`)**
  - Hotel listing with multi-filter sidebar (price range, star rating, amenities)
  - Sorting (price low-to-high, top-rated, popularity)
- **Stage 4: Hotel & Room Details (`HotelDetailPage.jsx`)**
  - Room comparison table & photo gallery
  - Sightseeing tour package add-on selector
- **Stage 5: Booking & Checkout (`BookingPage.jsx`)**
  - Guest details form & price breakdown
- **Stage 6: Guest Dashboard (`BookingsDashboardPage.jsx`)**
  - View, modify, or cancel reservations

> **Note on Routing:** In Stage 1, we focus on the core foundation and design system. When transitioning to multi-page navigation in Stage 2/3, `react-router-dom` will be introduced to route between these pages.
