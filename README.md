## Quick Start (Frontend)

To run the development server:

```powershell
# 1. Navigate into the frontend folder
cd frontend

# 2. Start the Vite dev server
npm.cmd run dev
```

Visit `http://localhost:5173` in your browser to explore the live customer homepage!
Use the top academic bar to toggle between the **Customer Homepage (Stage 2)** and the **Design System Foundation (Stage 1)**.

For full details, see the [Frontend Documentation](file:///c:/Project-Hotel-Management/frontend/README.md).
